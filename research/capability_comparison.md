## 2. Summary of Strategic Positions

### Where Semantiq Security Leads Codex Security:
1. **Deterministic Semantic Program Graph (SPG):** Semantiq possesses a genuine, typed, interprocedural code property graph with typed edges (`DATA_FLOW`, `CALLS`, `REACHES`). Codex Security has **no code graph at all** and relies on the LLM reading source files.
2. **Asynchronous Flow Modeling:** Semantiq models message queues, event brokers, background workers, and idempotency hazards with deterministic caller-to-worker linking. Codex has no specialized asynchronous flow representation.
3. **Dedicated Security Primitive Analysis:** Semantiq statically analyzes entropy sources (`id(self)`, weak PRNGs, timestamps) and correlates them with cookie defense flags (`httponly`, `secure`, `samesite`), enabling automated discovery of memory-address session flaws.
4. **Offline Independence:** Semantiq does not require proprietary cloud endpoints, vector embedding APIs, or specific model ecosystems to parse code and query graphs.

### Where Codex Security Leads Semantiq Security:
1. **Parallel Multi-Worker Deep Scan:** Codex's `DeepScanCoordinator` partitions large codebases across independent worker processes, aggregating results through a reducer. Semantiq runs single-threaded sequential turns.
2. **Two-Stage Finding Deduplication:** Codex clusters findings with vector embeddings and resolves overlaps using an LLM pairwise reviewer with inclusive merging. Semantiq relies on exact fingerprint hashing.
3. **Structured Finding Evidence Schema:** Codex's `codeEvidence` mandates 7 semantic roles (`user_input`, `entrypoint`, `propagation`, `root_control`, `sink`, `outcome`, `expected_control`) with connective explanations and ordered `rootCause` references.
4. **Epistemological Coverage & Deferred Work Ledger:** Codex explicitly separates proven findings from `coverage.deferred` (Proof Gaps), preventing speculative findings from polluting reports.
5. **Hardened Scan Contract Finalization:** A 3,411-line Python finalizer seals artifacts, generates SARIF 2.1.0 with security scores, and enforces strict JSON schema contracts.
6. **Enterprise Persistence & State:** Codex maintains 32 normalized SQLite tables tracking every scan, location, occurrence, embedding, triage verdict, and publication receipt.
