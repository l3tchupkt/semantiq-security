# Security Policy

## Reporting Security Vulnerabilities

If you discover a security vulnerability in Semantiq Security, please report it responsibly.

**Do not report vulnerabilities via public GitHub issues.**

Please send security reports to:
- **Maintainer:** Lakshmikanthan K ([@letchupkt](https://github.com/l3tchupkt))
- **Email:** `letchupkt@users.noreply.github.com`
- **Subject:** `[Vulnerability Report] Semantiq Security - <Brief Description>`

Please include:
1. Description of the vulnerability and attack vector.
2. Reproduction steps, proof-of-concept, or minimal repository demonstrating the issue.
3. Affected components, versions, and operating system.
4. Proposed patch or mitigation if available.

We acknowledge receipt of reports within 48 hours and coordinate responsible disclosure upon validation and remediation.
